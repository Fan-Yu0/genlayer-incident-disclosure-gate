GenLayer Intelligent Contract

Did the vendor actually disclose it?

Incident Disclosure Gate reads a public postmortem and decides whether it contains a dated timeline, a technical root cause, the affected scope, a remediation that was performed and a contact — inside the SLA the buyer's policy requires.

Extract

Every validator re-fetches the disclosure and extracts only the constrained facts. No summary is trusted.

Decide

Deterministic code maps the agreed facts to APPROVED, CONDITIONAL, BLOCKED or REVIEW_REQUIRED.

Consume

Supplier lists call is_compliant(incident_id) instead of trusting a support ticket.
